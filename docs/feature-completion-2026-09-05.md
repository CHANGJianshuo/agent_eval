**功能完善记录 · 2026-09-05**

本次针对[审查报告](feature-audit-2026-09-05.md)中用户选定的五类可信度问题和日常操作流程实施修复。没有改写已有任务的业务话术、评分标准或原始对话；验证使用临时项目和离线模型。

| 问题 | 完成的修改与验证 |
| --- | --- |
| 零权重假通过 | 非安全评分项必须使用正的有限权重；保存、启动与评分层拦截。旧结果读取时也不会据此给出通过结论。 |
| 失败用例消失 | 以完整用例清单合并结果与执行失败；2 条中失败 1 条显示完整评分 1/2。损坏或来自其他运行的结果作为异常展示，不会静默丢弃。 |
| 安全统计稀释 | 只以能作出安全结论的用例计算破防率，独立展示未知数和覆盖率。全部异常显示无法判断；红队复用普通 batch 的快照和运行管理。 |
| 人设维度无效 | 年龄、学历、性别、MBTI 等已进入模拟器输入；不据此推断现实群体的能力、态度或因果差异。禁止保存运行引擎不支持的维度键。 |
| 历史汇总与详情不同 | 启动时按统一结果模型校正旧数据索引，保留原始 trace。旧口径 HTML 需要重建，避免继续显示错误指标。 |
| 黑名单漏报 | 修复历史 `keywords`、`blacklist` 与 `banned_words` 参数名不一致导致的静默漏判，并补回归用例。 |

本地验证结果：350 项 Python 测试通过；默认跳过的 2 条浏览器流程已单独执行并通过；3 项前端契约测试通过；TypeScript 检查和生产构建通过。CI 已加入相同浏览器流程，远端 CI 尚未执行。

现有 5 个业务任务均通过启动校验，但仍有流程节点引用不存在的评分项；`rider_delivery_demo_0904` 另有 3 处触发条件缺少确定性覆盖。这些配置关系需要按业务标准补充，在页面保留明确提醒，不代造评分依据或宣称覆盖完成。
